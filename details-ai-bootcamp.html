Situation

  • Worked as a mechanical engineer applying AI/ML to physical simulations (FEA/CFD) — but as a user, not a builder.
  • Recognized a clear gap: unable to communicate fluently with AI engineers on model architecture, training, and deployment.
  • Decided to close that gap by enrolling in an intensive, government-funded AI engineering program.

Task

  • Complete an intensive 7-month full-stack AI engineering curriculum covering Computer Vision and NLP/LLM pipelines.
  • Build deployable AI projects spanning object detection, instance segmentation, retrieval-augmented generation, and generative AI.
  • Develop production-ready skills: model training, serving, cloud deployment, and performance optimization.

Action

  • Hands-on project-based learning across four core AI engineering domains:
  • Module 1 Object Detection
    Built a real-time pill recognition app using YOLOv8s — point a phone camera at pills and each one is instantly identified with a bounding box and label. Trained on a custom pill dataset and evaluated via mAP on Kaggle.
  • Module 2 Segmentation
    Trained a U-Net model to color-classify every pixel in a football broadcast frame — grass, sky, goalpost, and each player assigned a distinct color. Used Dice Loss to handle class imbalance between large background and small player regions.
  • Module 3 RAG System
    Built a document-based chatbot where a user uploads a PDF and asks questions — the AI finds the most relevant sentence and answers with the exact source highlighted. Used LangChain and FAISS for retrieval; iterated to reduce token cost while keeping answer quality.
  • Module 4 Generative AI
    Built an ad image generator where uploading a casual photo (e.g. a coffee cup) instantly produces a polished advertisement — same subject, professional lighting and styling. Fine-tuned a diffusion model on brand-specific images and deployed end-to-end via Docker.

Result

  • Successfully completed the full 7-month program with 3-tier project portfolio (beginner → intermediate → advanced).
  • Gained practical proficiency in the full AI engineering lifecycle: data preparation → model training → serving → deployment.
  • Strengthened capacity to integrate deep learning directly into engineering research pipelines (FEA/CFD + AI).
